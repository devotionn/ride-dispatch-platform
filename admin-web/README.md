# Admin Web

PC 调度管理后台，面向管理员和调度员，首期重点是订单人工调度与司机管理。

## 已实现工作面

- 管理员/调度员登录；
- 平台品牌名称与 Logo 上传/替换（管理员可修改，其他角色只读）；
- 服务端可撤销 Bearer Session；
- 订单列表、状态筛选和分页；
- 后台代客建单；
- 订单详情、派单历史和履约时间线；
- 有坐标订单的 10km 附近有效司机，及无坐标订单的人工候选司机；
- 人工首次派单；
- 待司机确认订单改派；
- 司机列表和新增司机/车辆；
- 司机详情运营/结算快照；
- 司机专属下单链接复制、二维码预览和 PNG 下载；
- 常用地点目录（搜索、新增、编辑、启用和停用）。

## 本地启动

要求 Node.js 22.18+，后端默认运行在 8080 端口。

```bash
cd admin-web
cp .env.example .env.local
pnpm install --frozen-lockfile
pnpm run dev
```

默认地址 `http://localhost:5174`，开发环境 `/api` 代理到 `http://localhost:8080`；如本机后端使用其他端口，可在 `.env.local` 设置 `VITE_DEV_API_TARGET` 覆盖代理目标。

## 地点与坐标

系统不集成商业地图 SDK，也不需要地图 Key。调度员可直接输入地址或从常用地点目录选择；纬度和经度可同时为空。只有订单上车点有坐标时，后台才显示附近司机距离排序；否则显示符合接单条件的司机供人工派单。
